8. Commands

Open Terminal in the launch-kit folder first (cd ~/Desktop/\$BLAME/launch-kit).

(a) Put the real contract address on everything

npm run kit -- --ca 0xYOUR_CONTRACT_ADDRESS

(b) Make a new blame card for any coin (live numbers)

npm run card -- 0xCOIN_ADDRESS
npm run card -- 0xCOIN_ADDRESS 7d      (or 1h, 6h, 24h)

(c) Re-render only the videos

npm run video

Other

npm run kit -- --refresh     fetch fresh $AI / $MEME / $BONER numbers, then re-render everything
npm run kit -- --no-video    images only (about a minute)
npm run check                run every check again
