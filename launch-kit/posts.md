# Blame the Stock — post copy

Every post below sits in its own grey box so you can copy it in one go. The checker (`npm run check`) counts each
box the way X does (a link always counts as 23 characters) and fails anything over 280.

**Slots** — swap these before posting:
`[CA]` contract address · `[COIN]` coin ticker without $ · `[STOCK]` stock ticker · `[X]` the coin's move ·
`[Y]` the stock's share of the move · `[LINK]` a link · `[NAME]` a coin name · `[TIME]` a time gap · `[S]` seconds · `[N]` a number · `[HANDLE]` your X handle.

**The $AI numbers** in the thread (−5.9%, 56% NVDA) are live chain numbers from Thu Nov 19, 12:12 AM ET
(the 24 hours of Wednesday, the day after Nvidia reported on Tuesday Nov 17). On posting day, run
`npm run card -- 0x2e8c31162b855a2ffa90f6f8634643ad6f111e18` and use the fresh numbers it prints.
