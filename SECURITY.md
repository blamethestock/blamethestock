# Security

## Stay safe

- **We never DM.** Anyone messaging you as Blame the Stock is not us.
- **No presale, airdrop or claim.** Any site or message offering one is a scam.
- **Never share your seed phrase or private key.** Not with us, not with anyone. We will never ask.
- **The only official $BLAME contract address is on [blamethestock.com](https://blamethestock.com).** Check it there before you buy.
- **Blame the Stock is read-only.** It never asks you to connect a wallet, sign or approve anything. If a page that looks like ours does, it isn't ours.

## Reporting a problem

Found a bug or security issue in this code or on the site? Open an issue in this repo. For anything that shouldn't be public, use **Security → Report a vulnerability** on this repo's GitHub page.

Please don't include wallet secrets or personal data in a report.
